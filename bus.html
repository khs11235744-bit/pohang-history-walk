버스 이동과 승하차

전세버스 1대의 실제 차량 크기·정원·운행 경로를 확인합니다. 시간표의 이동시간은 주행 측정값이 아닌 집결·승하차를 포함한 배정시간입니다.

이동시간 배정

구간배정사전 확인
학교 → 호미곶08:20–09:30 / 70분학교 승차·현지 하차·주차·집결
호미곶 → 북구 식당12:00–13:10 / 70분정확한 식당 주소·주행·단체 하차
식당 → 기념관14:00–14:20 / 20분탑산길 진입·회차·기념관 입장
기념관 → 수도산15:20–15:40 / 20분하산·승하차·공원 접근
수도산 → 학교16:30–17:10 / 40분학생 집결·학교 귀교·인원 확인

현장에서 확인할 것

  • 호미곶 광장·등대·박물관은 도보로 이어 봅니다. 지정 육상 활동 구간과 배출·손 위생·화장실을 확인합니다.
  • 수화식당은 우선 협의 후보입니다. 단체 수용·주차·메뉴가 맞지 않으면 북구 식당으로 대체하고 기사에게 최종 주소를 전달합니다.
  • 기념관의 대표 지도 핀과 실제 대형버스 승하차 장소를 구분합니다. 탑산길 회차·대기·학생 이동 동선을 기관과 기사에게 확인합니다.
  • 수도산의 계단·경사·보행 지원 대체 동선과 교사 해설 집결 지점을 확인합니다.

지연·기상 대응

해경 방문 미성립 시 박물관 관람·기록 공유·휴식으로 바꾸고 12:00 북구 출발 목표를 유지합니다. 교통 지연·기상 악화 때는 선택 활동과 야외 구간을 조정하여 식사·안전·귀교 시간을 확보합니다.
