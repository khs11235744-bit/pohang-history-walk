버스 이동과 승하차

전세버스 1대의 실제 차량 크기·정원·운행 경로를 확인합니다. 시간표의 이동시간은 주행 측정값이 아닌 집결·승하차를 포함한 배정시간입니다.

이동시간 배정

구간배정사전 확인
학교 → 호미곶08:20–09:30 / 70분학교 승차·현지 하차·주차·집결
호미곶 → 수화식당11:40–12:30 / 50분정확한 식당 주소·주행·단체 하차
수화식당 → 기념관13:30–13:50 / 20분탑산길 진입·회차·기념관 입장
기념관 → 수도산14:50–15:10 / 20분하산·승하차·공원 접근
수도산 → 학교16:20–17:10 / 50분학생 집결·학교 귀교·인원 확인

현장에서 확인할 것

  • 호미곶 광장·등대·박물관은 도보로 이어 봅니다. 지정 육상 활동 구간과 배출·손 위생·화장실을 확인합니다.
  • 수화식당에서 12:30~13:30 식사·휴식을 진행합니다. 단체 수용·주차·메뉴·알레르기 대체·학교회계 결제를 사전 확인하고 기사에게 최종 승하차 위치를 전달합니다.
  • 기념관의 대표 지도 핀과 실제 대형버스 승하차 장소를 구분합니다. 탑산길 회차·대기·학생 이동 동선을 기관과 기사에게 확인합니다.
  • 수도산의 계단·경사·보행 지원 대체 동선과 교사 해설 집결 지점을 확인합니다.

장소 지도 · 사전답사 확인표

지연·기상 대응

해양 플로깅과 호미곶파출소 해양 안전교육은 관계기관 협의와 현장 안전을 우선합니다. 교통 지연·기상 악화 때는 야외 활동 시간을 조정하되 12:30 수화식당 식사와 17:10 공식 종료 시간을 기준으로 운영합니다.
