# HADES 개선안 100

> 2026 포항고 인문사회부 인문학 역사기행 사이트. 유사한 디지털 필드가이드의 장점을 참고하되, 포항 지역사 답사라는 목적에 맞춰 다시 설계한다.

## 역사·좌표 정확도
1. [x] 주요 답사지 주소와 위·경도를 한 데이터 파일에서 관리한다
2. [x] 주소·좌표의 출처 등급을 ‘공공데이터/공식주소/주소지오코딩/현장실측’으로 구분한다
3. [x] 사라진 근현대 건물은 확인 전 임의 좌표를 만들지 않는다
4. [ ] 간독창고·적산가옥 위치를 사전답사에서 실측한다
5. [ ] 하마다 어업왕국 관련 지점을 향토사 해설자와 교차검증한다
6. [ ] 옛 영일어업조합 위치를 지적도·옛 지도와 현재 지도에 겹쳐 검증한다
7. [ ] 학산동 100번지의 역사적 의미와 현 위치를 검증한다
8. [x] 각 지점마다 ‘확정 사실/추정/당시 주장’을 시각적으로 구분한다
9. [x] 『포항지』 원문의 식민지적 어휘를 그대로 설명문에 사용하지 않는다
10. [ ] 현장 답사 후 좌표 오차와 출입구 위치를 수정 기록한다

## 현장 동선·지도
11. [x] 전체 경로를 한 화면 지도에 표시한다
12. [x] 각 핀에서 Google·네이버·카카오 지도 검색으로 바로 이동한다
13. [ ] 버스 이동과 도보 이동을 색 또는 선형으로 구분한다
14. [ ] 버스 승하차 지점을 방문지 핀과 별도로 관리한다
15. [ ] 40명 집결 가능한 공간을 각 장소마다 표시한다
16. [ ] 화장실 위치를 지도에 보조핀으로 추가한다
17. [x] 장소 간 예상 이동시간과 10분 버퍼를 함께 표시한다
18. [ ] 현장모드에서 ‘다음 장소’ 버튼 하나로 이동하게 한다
19. [ ] GPS와 실제 위치가 멀면 ‘좌표는 안내용’ 경고를 표시한다
20. [ ] 우천 시 야외 지점을 자동으로 숨기는 대체 경로 토글을 둔다

## 사료·해설
21. [x] 각 장소에 3~4분 발표 가능한 소논문형 글을 제공한다
22. [x] 발표문 첫 문단에 한 문장 논지를 둔다
23. [x] 각 글 끝에 학생 질문 하나를 둔다
24. [ ] 옛 지도와 현재 지도를 좌우 비교할 수 있게 한다
25. [x] 사진은 장식이 아니라 설명 대상이 되도록 캡션을 쓴다
26. [x] 식민지기 일본인 기록은 서술자의 위치를 명시한다
27. [x] 3·1운동의 ‘만세운동/소란’처럼 명명 차이를 사료비판 활동으로 만든다
28. [x] 수도산 ‘수덕무강’ 휘호는 추정 수준을 명시한다
29. [x] 항만·철도·상수도를 ‘근대화=긍정’으로 단순화하지 않는다
30. [ ] 현장에서 교사가 30초 보충할 ‘한 문장 팁’을 별도 제공한다

## 반복 순서

- H — History: 사료·용어·역사적 맥락
- A — Accuracy: 주소·좌표·운영시간·출처
- D — Design: 답사수첩다운 시각 언어, 반응형
- E — Experience: 학생 현장 사용성과 교사 운영성
- S — Safety & Sources: 안전·개인정보·사료비판·검증

완료 표시가 있어도 실제 현장 확인이 필요한 항목은 사전답사 후 다시 PASS 판정한다.
