# SOURCES — 포항고 인문학 역사기행

## 1. 핵심 사료·연구서
- 김진홍 엮고·옮김, 『일제의 특별한 식민지 포항』
  - 수록된 『포항지』 계열 식민지기 기록은 원저자의 위치와 편향을 전제로 비판적으로 사용한다.
  - 사이트의 1917·1925·1936 지도 및 1930년대 포항 거리·시장·항만 사진은 사용자가 제공한 자료와 기존 로컬 역사자료 자산에서 답사 관련 이미지만 선별해 사용한다.
  - 본문 설명은 원문을 길게 전재하지 않고 현장 수업용으로 새로 요약·구성했다.

## 3. 동빈항 미시유적 검증
- 2026.8 포항문화역사길라잡이 ‘동빈항의 문화와 역사’ 답사 보도
  - 확인된 답사 순서: 송도교 → 옛 죽도시장터 → 포항개항지정기념비 → 간독창고·적산가옥 → 하마다 어업왕국 관련 지점 → 영일어업조합 관련 지점 → 학산동 100번지

  - 동빈동 영일어업조합(1914) 등 동빈항 역사사진·자료 확인에 활용
- 국가기록원
  - 1933년 영일어업조합 형산강 잔교 설치·하천부지 점용 관련 기록 확인
- 현장 접근 앵커
  - 동빈큰다리 중심: 36.040095, 129.371249
  - 포항개항지정기념비는 동빈큰다리 북측 동빈부두 구간까지 문헌·답사기록으로 좁혔으나, 표석 자체의 최종 GPS 핀은 사전답사에서 실측한다.

## 4. 좌표 표기 원칙
1. 주요 현재 시설은 공식 주소 + 공개 지도 좌표를 함께 쓴다.
2. 옛 지번을 현재 지번으로 임의 변환하지 않는다.
3. 사라진 건물·시설은 ‘현장 실측’ 또는 ‘옛 지적도 대조’ 전까지 정밀 좌표를 공개하지 않는다.
4. 버스 승하차 위치와 시설 중심좌표는 별개로 관리한다.
5. 10월 17일 행사 전 최종 사전답사에서 실제 출입구·보행동선·집결공간을 다시 확인한다.
