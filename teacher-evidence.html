학생 응답을
세특 근거 묶음으로 연결합니다.

Google Forms 응답 시트에서 CSV를 내려받아 사전·사후 파일을 선택하면 학년·반·번호·이름을 기준으로 학생별 탐구 증거를 연결합니다. 파일은 브라우저 안에서만 처리하며 서버로 업로드하지 않습니다.

기록 원칙 이 페이지가 만드는 것은 ‘세특 근거 요약’입니다. 실제 학교생활기록부에는 교사가 직접 관찰·평가한 내용과 학생의 실제 발표·학습지·기사 등 결과물을 확인하여 입력합니다. 학생 자기응답만으로 최종 세특을 확정하지 않습니다.
01

응답 CSV 불러오기

Google Forms → 응답 → Sheets에서 각각 CSV로 내려받은 뒤 선택합니다.

02

응답 연결 현황

CSV 두 파일을 선택하면 학생별로 자동 연결됩니다.
03

학생별 세특 근거 묶음

탐구 질문 → 사료 → 현장 증거 → 교과 개념 → 생각 변화 → 논증 → 협업 → 후속 탐구의 흐름으로 검토합니다.

교사 확인 체크 실제 현장에서 확인한 행동인가 / 학생 제출 결과물과 일치하는가 / 성취기준·교과 개념과 관련되는가 / 과장된 자기평가를 그대로 사용하지 않았는가 / 질문과 근거, 결론 사이의 연결이 확인되는가.
