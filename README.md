# 포항, 물길에서 전쟁까지

2026년 10월 17일 포항고등학교 인문사회부 인문학 역사기행용 정적 웹사이트.

## 공개 페이지
- index.html: 시작 페이지
- student.html: 학생 공지·지도·현장 미션
- essays.html: 답사지별 3~4분 발표문
- improvements.html: HADES 개선 100

## 운영 페이지
- teacher.html: 교사용 일정·좌표·예약·안전·예산
  - noindex 처리했지만 보안 페이지가 아니므로 학생 개인정보를 저장하지 않는다.

## 디자인 원칙
답사수첩·향토사 자료집의 편집 언어를 사용한다. 일반 SaaS 랜딩페이지처럼 둥근 카드, 글로우, 그라디언트, 의미 없는 배지를 남발하지 않는다.

## 역사 서술 원칙
『일제의 특별한 식민지 포항』의 원전 계열 자료는 식민지기 일본인 서술자의 위치와 편향을 함께 표시한다. 식민지 기반시설의 확충과 식민지 지배의 정당성은 별개의 문제로 다룬다.

## 좌표 원칙
검증한 주요 답사지 좌표만 학생 지도에 공개한다. 간독창고·하마다 어업왕국·옛 영일어업조합·학산동 100번지 등 미시유적은 사전답사에서 실측 검증한 뒤 추가한다.

## 실행
정적 파일이므로 웹서버에서 루트를 열면 된다. GitHub Pages 배포를 기준으로 상대경로만 사용한다.
