# 포항, 물길에서 전쟁까지

2026년 10월 17일 포항고등학교 인문사회부 인문학 역사기행용 디지털 필드가이드.

- 시간: 08:30–16:30
- 대상: 포항고등학교 학생 약 40명
- 핵심 흐름: 전통 생활사 → 나루·시장 → 식민지 항구도시 → 산업유산 → 근대 상수도 → 한국전쟁의 기억

## 공개 페이지
- `index.html` — 메인
- `student.html` — 학생 공지·현장 지도·미션·개인 답사기
- `essays.html` — 장소별 3~4분 발표문
- `archive.html` — 1917·1925·1936 옛 지도와 현재 지도 비교, 1930년대 역사사진
- `improvements.html` — HADES 개선 100

## 교사용 페이지
- `teacher.html` — 분 단위 일정, 좌표, 기관 연락, 안전·보험·예산, 미시유적 검증상태
- `teams.html` — 학생 40명을 7·7·7·7·6·6명으로 나누는 로컬 팀 편성 도구
- `bus.html` — 45인승 기준 이동 가능성, 하차·재승차 앵커, 골목·주차·회차 위험과 우천 대안

교사용 페이지는 `noindex`이지만 보안 페이지가 아니다. 학생 명단·보호자 연락처·건강정보·보험용 개인정보는 저장소에 기록하지 않는다. `teams.html`의 이름과 배정 결과는 브라우저 로컬저장소에만 보관된다.

## 현장 오프라인
`sw.js`와 `manifest.webmanifest`를 포함한다. 한 번 접속한 뒤에는 핵심 안내·발표문·역사사진을 오프라인에서도 다시 열 수 있도록 구성했다. 외부 지도 타일은 네트워크 상태에 따라 제한될 수 있다.

## 디자인
답사수첩·향토사 자료집·전시도록의 편집 언어를 사용한다. 일반 SaaS 랜딩페이지처럼 둥근 카드, 글로우, 그라디언트, 의미 없는 배지를 기본 문법으로 쓰지 않는다.

## 역사 서술
『일제의 특별한 식민지 포항』의 원전 계열 자료는 식민지기 일본인 서술자의 위치와 편향을 함께 표시한다. 항만·철도·상수도 같은 기반시설의 확충과 식민지 지배의 정당성은 별개의 문제로 다룬다.

## 좌표
검증한 주요 방문지만 학생 지도에 공개한다. 간독창고·하마다 관련 지점·옛 영일어업조합·학산동 100번지처럼 현장 정밀좌표가 불확실한 미시유적은 사전답사에서 실측·교차검증 후 추가한다.
